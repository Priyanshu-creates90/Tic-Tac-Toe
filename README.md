# ❌⭕ Tic-Tac-Toe Game

A classic interactive **Tic-Tac-Toe** game built using clean vanilla **HTML5**, **CSS3**, and **JavaScript**. Features real-time turn tracking, automatic win/draw detection, and full game resetting[cite: 5].

🌐 **Live Demo:** [https://tic-tac-toe-beige-two.vercel.app/](https://tic-tac-toe-beige-two.vercel.app/)

---

## ✨ Features

* **Two-Player Gameplay:** Alternate turns between Player X and Player O on a 3x3 grid[cite: 5].
* **Win & Draw Detection:** Evaluates winning patterns (rows, columns, diagonals) after every move and displays the winner message[cite: 5].
* **Reset & New Game:** Built-in buttons to clear the board and start a new game instantly[cite: 5].
* **Responsive Layout:** Clean design styled with modern CSS for smooth interaction[cite: 5].

---

## 🛠️ Tech Stack

* **HTML5:** Game board markup and popups[cite: 5].
* **CSS3:** Custom layout styling and interactive UI state transitions[cite: 5].
* **JavaScript (ES6):** Turn management, winning pattern checking algorithm, and DOM updates[cite: 5].
